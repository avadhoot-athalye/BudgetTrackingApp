# 💰 BudgetTracker – v1

BudgetTracker is a personal finance management web application that helps users track expenses, allocate monthly budgets, and gain insights into their spending habits.  
The goal of v1 is to provide a **simple, secure, and user-friendly way** to manage personal finances.

---

## 🚀 Features (Version 1)

### 👤 User Management
- User registration and login
- Secure authentication using JWT
- User-specific data isolation

---

### 💸 Expense Management
- Add, edit, and delete expenses
- Track expenses by:
  - Amount
  - Expense category (Food, Travel, Rent, etc.)
  - Date
  - Notes
- View expenses in a monthly list format

---

### 📊 Budget Management
- Allocate monthly budgets per expense category
- Update budget allocations anytime
- Track spending against allocated budgets

---

### 📈 Budget vs Expense Overview
- View total allocated budget
- View total expenses
- Remaining budget calculation
- Visual indicators for overspending

---

### 🔍 Filters & Sorting
- Filter expenses by:
  - Date range
  - Expense category
- Sort expenses by:
  - Date
  - Amount

---

### 🔐 Security
- JWT-based authentication
- Role-based access control (User)
- Secure REST APIs using Spring Security

---

## 🛠️ Tech Stack

### Backend
- Java 8+
- Spring Boot
- Spring Security
- Spring Data JPA
- Postgres

### Frontend
- Angular
- Bootstrap
- Chart library (for basic graphs)
